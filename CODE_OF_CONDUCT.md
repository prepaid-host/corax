# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and focus on what is best for the community.
Harassment of any kind is not tolerated.

Instances of abusive, harassing, or otherwise unacceptable behaviour may be reported to
the maintainers via the contact listed in the repository's GitHub profile. All reports
will be reviewed and investigated promptly and fairly.
